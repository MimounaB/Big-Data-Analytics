# TP01 — Python Web Scraping

## Objective
Extract quotes and their authors from a website using Python.

## Data Source
- Website: [مقولات وحكم](https://arabic-quotes.com/quotes)
- URL: https://arabic-quotes.com/quotes

## Tools and Libraries
- **Requests:** Fetch web pages.
- **BeautifulSoup:** Parse HTML and extract quotes and authors.
- **Pandas:** Organize and export the extracted data to CSV.

## Output
- `TP01_Web_Scraping.ipynb`: Jupyter Notebook containing the code.
- `arabic_quotes.csv`: Dataset containing 4,870 unique quote-author pairs after removing duplicate pairs.

## Notes
The dataset was collected from the website's paginated quote pages and exported as a CSV file.
