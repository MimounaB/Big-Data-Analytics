
# TP03 — تحليل البيانات باستخدام Power BI

## 1. وصف المشروع
يهدف هذا المشروع إلى تحليل بيانات مبيعات متجر إلكتروني باستخدام برنامج Power BI، وإنشاء لوحة معلومات تفاعلية تساعد على استكشاف أداء المبيعات خلال الفترة الممتدة من 2009 إلى 2011.

## 2. مجموعة البيانات
- **اسم البيانات:** Online Retail II
- **الفترة الزمنية:** 2009–2011
- **المصدر:** UCI Machine Learning Repository

تحتوي البيانات على معلومات حول الفواتير والمنتجات والكميات والأسعار والتواريخ والعملاء والدول.

## 3. الأدوات المستعملة
- Microsoft Power BI
- Power Query لتنظيف البيانات وتجهيزها
- DAX لإنشاء مؤشرات الأداء

## 4. محتويات لوحة المعلومات
تتضمن لوحة المعلومات:
- مؤشرات رئيسية للمبيعات وعدد الفواتير والعملاء ومتوسط قيمة الفاتورة.
- رسمًا بيانيًا للمبيعات حسب الدولة.
- رسمًا زمنيًا لتغير المبيعات.
- رسمًا لأفضل 10 منتجات حسب قيمة المبيعات.
- فلاتر تفاعلية حسب الدولة والتاريخ.

## 5. الملفات المرفقة
- `TP03.pbix`: ملف مشروع Power BI.
- `TP03_dashboard.png`: صورة لوحة المعلومات النهائية.
- `TP03_report.pdf`: تقرير مختصر يلخص النتائج.

## 6. الهدف من المشروع
تطبيق تقنيات تحليل البيانات وتصويرها باستخدام Power BI، وتقديم النتائج في لوحة معلومات تفاعلية تسهّل فهم مؤشرات المبيعات واستكشافها.
